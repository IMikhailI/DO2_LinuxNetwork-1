## Темы

- сети и маски с **ipcalc**;
- localhost и диапазоны IP-адресов;
- статические маршруты и маршрутизация между машинами;
- измерение пропускной способности через **iperf3**;
- сетевой экран и диагностика **nmap**;
- динамическая настройка адреса через DHCP;
- NAT и SSH tunnels.

Репозиторий содержит отчёт по лабораторной работе; готового сетевого сервиса для запуска здесь нет.
